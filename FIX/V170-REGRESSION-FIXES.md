# Garuda Fitness Zone V170

This release addresses the reported V169 regressions: profile lookup across member ID/code aliases, post share links using the app's actual database state, member profile navigation label, duplicate portal header sign-out, general Back behavior, and homepage entry scroll reset.

Deploy by replacing the repository contents with the `FIX` folder contents and pushing to GitHub. Do not run the seed script against production.

Automated syntax/static checks do not replace live testing against the Render deployment, authenticated account data, and real mobile browser.
